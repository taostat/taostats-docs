The taostats API gives you full access to data from the Bittensor ecosystem, - the same data used to power [taostats](https://taostats.io) .

To begin, you'll need an [Taostats API Key](doc:the-taostats-api).  

Coming soon: Role Based Access Control for organizations and projects, billing and more!

<br />

Not sure how to get started?  We have a GitHub repository of example scripts:

[Awesome Taostats Examples](https://github.com/taostat/awesome-taostats-api-examples)
