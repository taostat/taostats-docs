Hotkeys are part of your Bittensor wallet, and are used to perform actions on the chain in a secure fashion.  [Coldkeys](doc:coldkeys) can have multiple hotkeys.  Each hotkey can be used to:

- Register a miner or validator on a subnet. (You can use the same hotkey on multiple subnets, but you cannot reuse the same hotkey on a single subnet).
- Use a validator's hotkey to stake tao.

In both of these cases, staking rewards are added to the hotkey wallet. 

All tao added to a hotkey remains in **your** wallet, and can be easily transferred back to the coldkey.
