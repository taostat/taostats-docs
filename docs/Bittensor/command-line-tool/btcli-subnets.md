Commands around subnets in the Bittensor command line tool.  

```
                                                                                                                                                                      
╭─ Options ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                                                                                         │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Subnet Creation & Management ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ create            Registers a new subnet.                                                                                                                           │
│ lock-cost         Shows the required amount of TAO to be locked for creating a new subnet, i.e., cost of registering a new subnet.                                  │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Subnet Information ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ hyperparameters   Shows a list of the hyperparameters for the specified subnet.                                                                                     │
│ list              List all subnets and their detailed information.                                                                                                  │
│ metagraph         Shows the metagraph of a subnet.                                                                                                                  │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Neuron Registration ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ pow-register      Register a neuron (a subnet validator or a subnet miner) using Proof of Work (POW).                                                               │
│ register          Register a neuron (a subnet validator or a subnet miner) in the specified subnet by recycling some TAO.                                           │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
```

<br />

# Subnet Creation

## create

Creates a subnet

## lock-cost

Displays the current lock cost in tao to create a subnet.
