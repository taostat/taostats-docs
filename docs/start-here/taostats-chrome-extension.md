A chrome extension giving access to your wallets on chain

<Image border={false} alt="Taostats Chrome extension wallet popup showing total portfolio with hidden balances, Send and Receive buttons, and a list of saved accounts" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/21b8344736031208.png" />

# Installation

from the [Chrome Extensions Store](https://chromewebstore.google.com/detail/taostats-the-bittensor-wa/khdnjjgidjjbjpececegbfglalchffpo).  You can get marketing information about the app at [https://taostats.io/bittensor-chrome-wallet](https://taostats.io/bittensor-chrome-wallet)

# Add your wallet

You need to add your wallet address to the extension:

<Image border={false} alt="Taostats Chrome extension account toolbar with the "+" add-account button hovered, showing its "Add account" tooltip" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/f56683f7ae4f4f1f.png" />

You have 4 options:

<Image border={false} alt="Taostats Chrome extension add-wallet menu with four options: New Bittensor Account, Import via Recovery Phrase, Watch Bittensor Account, and Connect Ledger" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/66585b3860227502.png" />

1. New account:  Will create a new 5xxx account on chain for you.
2. Import using your seed phrase (mnemonic)
3. Watch an account - get details, track balances, but you cannot trade.
4. Ledger - connect your ledger to Taostats.

# stake

<Image border={false} alt="Taostats Chrome extension wallet view with hidden balances and inline Stake and Unstake buttons on the TAO row above subnet positions" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/fb08caf6e6c067d1.png" />

For any wallet/any position, you can stake/unstake right from the wallet. (note that balances are hidden. This is also a feature of the extension.  When not taking screenshots for the docs - you can see your actual balances.)
