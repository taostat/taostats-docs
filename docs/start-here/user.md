**Users** interact with applications built on top of Bittensor. These applications make API calls into the network, and the user does not need to know the app is powered by Bittensor or have any knowledge of the ecosystem.

> 📘 This page is being expanded. For a plain-language introduction to the network these applications run on, see [Getting started with Bittensor](/docs/getting-started-with-bittensor).

## Key points

* Applications can be free or paid, as their developers decide.
* There is no requirement that the revenue stream uses the TAO token — payments could be fiat by credit card or any other currency.
* From the user's perspective, Bittensor is invisible infrastructure powering the product they use.
