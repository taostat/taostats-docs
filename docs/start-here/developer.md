**Developers** build applications that use the commodities produced by Bittensor subnets. Where validators provide gateway access to the network, developers who are not aligned with a validator use an API key to query the network through a participating validator.

> 📘 This page is being expanded. To start building on Taostats data, see [Getting started with the Taostats API](/docs/getting-started-with-taostats-api) and the [API Reference](/api-reference/).

## Key points

* Obtaining and interacting with data can vary from subnet to subnet.
* Products such as [nineteen.ai](https://nineteen.ai/) make interaction with many subnets easy via a single API key.
* Taostats exposes network and subnet data through its [API](/api-reference/), so developers don't have to run their own indexer.
