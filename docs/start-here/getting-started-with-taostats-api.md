Visit [https://taostats.io/pro/](https://taostats.io/pro/) to sign up for an API key.

1. Sign in with your favorite 3rd party authentication.

2. <Image border={false} alt="Taostats API dashboard for a project showing a "Create API Key" button and a Usage section" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/8626e87ead05a959.jpg" />
3. Click Create API key to generate your API key.
