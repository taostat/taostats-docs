# sudo wallet

[https://beta.taostats.io/account/5GLKGJdjCwBYgtim7F4eZCxDC3bMe9VvhCnpG2k9ihdyPX9p](https://taostats.io/account/5GLKGJdjCwBYgtim7F4eZCxDC3bMe9VvhCnpG2k9ihdyPX9p)

This is a SUDO wallet that runs the Bttensor chain.  In April 2022, there was an issue where many balances read zero.  To resolve this, all the tao was accumulated on his wallet and re-distributed to owners:

![](https://files.readme.io/1664858c333f7de6dd6be0b5b90808c87eaca1d89a57a5ae4529c8120a170885-image.png)

The discussion can be found in the [Bittesnor Discord](https://discord.com/channels/799672011265015819/830075335084474390/968959268873187388) This wallet is interesting as the 255k tao appeared in the wallet - there is no extrinsic for its arrival.
