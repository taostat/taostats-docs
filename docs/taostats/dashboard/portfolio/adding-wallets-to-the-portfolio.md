The search box at the top of the portfolio page allows you to search any wallet.  Once loaded, click "Add Account" to save this wallet with a name.  In the screenshot above there are 6 wallets saved.

![](https://files.readme.io/8c14fa1130c7397605a695ca83a871c8b2bee6ce76379b007e95724248708566-image.png)

<br />

Clicking the arrow carat displays the list of saved wallets. Clicking loads that wallet's details.
