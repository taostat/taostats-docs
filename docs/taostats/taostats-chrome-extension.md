# Installation

from the [Chrome Extensions Store](https://chromewebstore.google.com/detail/taostats-the-bittensor-wa/khdnjjgidjjbjpececegbfglalchffpo).  You can get marketing information about the app at https://taostats.io/bittensor-chrome-wallet

<br />

# Add your wallet

You need to add your wallet address to the extension:

![](https://files.readme.io/566cf367c61a50dff423e3dc1ee183de31807d82e850c65763962753667e7768-image.png)

<br />

You have 4 options:

![](https://files.readme.io/fd556a0f2520e25d3adbc071607787c14d0ab1d287904d01d985283ed7bf0c65-image.png)

<br />

1. New account:  Will create a new 5xxx account on chain for you.
2. Import using your seed phrase (mnemonic)
3. Watch an account - get details, track balances, but you cannot trade.
4. Ledger - connect your ledger to Taostats.

# stake

![](https://files.readme.io/644bca39aff58025a1a9dc5d82b32154bbb833b475e1629970fb19f9f8e4a2d4-image.png)

<br />

For any wallet/any position, you can stake/unstake right from the wallet. (note that balances are hidden. This is also a feature of the extension.  When not taking screenshots for the docs - you can see your actual balances.)
