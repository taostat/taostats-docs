[https://x.taostats.io/coldkey/](https://x.taostats.io/coldkey/)&lt;coldkey&gt;

<br />

The top of the coldkey page has a summary. This coldkey has 66 active hotkeys running 100 different neurons. (A single hotkey can be used in multiple subnets).
