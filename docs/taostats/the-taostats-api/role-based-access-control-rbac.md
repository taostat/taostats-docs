Every taostats developer account is built of organizations with projects.

# taostats organization

An organization can hold many projects.

Each organization can also have multiple users whoa re able toa ccess the dashboard, create API keys, add payment methods, etc.

# taostats project

Each project has one API key.  To update your API key, create a new project and delete the old one.
