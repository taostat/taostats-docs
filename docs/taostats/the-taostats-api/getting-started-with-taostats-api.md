# Get an API key

Visit [https://dash.taostats.io/](https://dash.taostats.io/) to sign up for an API key.

1. Sign in with your favorite 3rd party authentication.

   <Image align="center" width="50% " src="https://files.readme.io/2078c62-Screenshot_2024-06-24_at_11.27.09.jpg" />
2. Taostats uses a concept of [Organisations and projects](doc:role-based-access-control-rbac) to host API keys.  Create an Organisation:

<Image align="center" src="https://files.readme.io/3c99063-Screenshot_2024-06-24_at_11.28.33.jpg" />

1. Give it a name and description: 

   <Image align="center" width="50% " src="https://files.readme.io/b404001-Screenshot_2024-06-24_at_11.28.54.jpg" />
2. Each API key will be associated withe a project in your organization. Create a project to obtain an API key: 

   <Image align="center" src="https://files.readme.io/16b9292-Screenshot_2024-06-24_at_11.30.49.jpg" />
3. Click Create API key to generate your API key.
