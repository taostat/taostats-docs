How to use the TradingView chart

<Image border={false} alt="Taostats subnet TradingView candlestick chart with top toolbar, left drawing-tool sidebar, volume histogram, and price and date axes" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/27c8a344ca549c1b.png" />

Each subnet has a TradingView chart showing the price of alpha over time. These charts are easily configurable, with many different options, and the same tools and timeframes you'd use to read a <a href="https://www.tradingview.com/symbols/BTCUSD/" target="_blank" rel="noopener noreferrer">BTCUSD chart</a>, applied to subnet alpha.

The default time for each point is 1 hour:

<Image border={false} alt="Taostats subnet TradingView interval selector dropdown grouping minute, hour, and day timeframes with the active interval highlighted" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/4a00a90382e4bf82.png" />

The display can be updated

<Image border={false} alt="Taostats subnet TradingView chart-type dropdown listing bar, candle, line, area, and column display styles with the active type highlighted" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/cd30878bd1756b18.png" />

Your settings will be saved, and repeated across all subnets.
