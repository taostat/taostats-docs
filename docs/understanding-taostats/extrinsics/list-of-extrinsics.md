Describes the Extrinsics table at Taostats

<Image border={false} alt="Taostats extrinsics list page, a live table with extrinsic ID, name, account, height, result, and time columns plus filter controls" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/b433c8bd12a5c2d0.png" />

The extrinsics table updates with live data on the latest extrinsics published to the chain.

* **Extrinsic ID**: The extrinsic ID on chain (the format is: Block number - counter)
* **Name**: The [Extrinsics](/docs/extrinsics-and-events) that was called.
* **Account**: The coldkey that called the extrinsic
* **Height**: The block number
* **Result**: Did it succeed or fail
* **Time**: When the extrinsic occurred (mouse over for exact time)
