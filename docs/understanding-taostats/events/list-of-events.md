A live table of events called on the chain

<Image border={false} alt="Taostats events list page, a live table with event ID, name, pallet, phase, extrinsic ID, and time columns plus filter controls" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/1f3d56288a22cb30.png" />

* **Event ID**: Unique Identified for the event on chain
* **Name**: Event Name
* **Pallet**: Type of event called
* **phase**: Phase of the event
* **Extrinsic**: Extrinsic related to the event
* **Time**: When the Events were called.
