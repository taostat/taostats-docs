The **hotkey view** on Taostats is a detailed page for a single hotkey — for a miner or validator, it shows performance, stake, emissions, and per-subnet activity for that specific key.

> 📘 This page is being expanded. To see all hotkeys under one account first, use the [Coldkey view](/docs/coldkey-view).

## Key points

* A **hotkey** is the online key a neuron uses to validate or mine; it earns the emissions shown on this view.
* The hotkey view drills into one specific miner or validator — the counterpart to the account-wide [coldkey view](/docs/coldkey-view).
* For validators, this is where per-subnet returns, VTrust, and dividends surface.
