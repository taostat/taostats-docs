Build your own tooling and products using the data from Taostats.

The Taostats API surfaces the data you want to uncover form the Bittensor ecosystem. No longer must you dig through Python code and device ways to extract the data - the Taostats team has done this for you, and made it easy to retrieve any data from the Bittensor ecosystem.

To use the API, you'll need an API key.

# Get an API key

Visit [taostats.io/pro](https://taostats.io/pro)  to sign up for an API key.

1. Sign in with your favorite 3rd party tool.

   <Image border={false} alt="Taostats API sign-in card headed "Get Started with the taostats API today" with Google, GitHub, and Email login buttons" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/6a493690bcdf7d7b.jpg" />
2. Create an Organisation:

   <Image border={false} alt="Taostats API "Your Organisations" section with a "Create Organisation" card prompting the user to start by creating an organisation" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/4f160819fac1eed7.jpg" />
3. Give it a name and description:

   <Image border={false} alt="Taostats API "Create New Organisation" dialog with Name and Description fields filled in and a Create Organisation button" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/0a7dcc7530cc459a.jpg" />
4. Each API key will be associated with a project in your organization. Create a project to obtain an API key:

   <Image border={false} alt="Taostats API "docs project" dashboard with a "+ Create API Key" button above a Usage panel" src="https://raw.githubusercontent.com/taostat/taostats-docs/v5.0/docs-assets/img/8626e87ead05a959.jpg" />
5. Click Create API key to generate your API key.
