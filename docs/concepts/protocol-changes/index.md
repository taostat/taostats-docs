Recent and upcoming protocol-level changes on Bittensor, each with a full explainer.

* [**Root Reborn**](/docs/tldr) — Root dividends re-bought into a validator-curated basket (PR #2968, live in v441).
* [**Conviction v2**](/docs/conviction-v2) — The revised conviction-locking mechanism (PR #2658).
* [**Price-based emission shares**](/docs/price-based-emission-shares) — Subnet emissions switched to price-based shares (PRs #2779 + #2781).
* [**The emission gate**](/docs/emission-gate) — Emission gating mechanics (spec 440).
* [**Miner collateral**](/docs/miner-collateral) — Collateral requirements for miners (PRs #2953 + #2960).
* [**Runtime 445**](/docs/runtime-445) — Fees recycled not paid to authors, miner-burn scaling restored, EVM precompile expansion (spec 445).
* [**Shorting**](/docs/shorting) — Fixed-Liability Covered Continuous-Unwind shorting model (PR #2764).
