# Yield Values

Change the subnet in the left dorpdown to see results in other subnets

* **Validator**: Validator Name
* **STAKE**: Stake held in the subnet
* **1H APY**: Actual returns in the last hour - extrapolated to a year.
* **1D APY**: Actual returns in the last day - extrapolated to a year.
* **1W APY**: Actual returns in the last week - extrapolated to a year.
* **1M APY**: Actual returns in the last month - extrapolated to a year.
